# 🎓 高中全科知识库（网页版）

单文件 `index.html`：高中三年 **语文 / 数学 / 英语 / 物理 / 化学 / 生物** 六科的重点、难点、考点知识库，科幻风动态界面，**双击即可打开浏览**（无需联网、无需服务器）。

## 内容规模
- 6 大学科 · 28 个学段 · 165 个知识模块 · 2400+ 条知识点
- 每个模块四层结构：「📖 课本知识点」（课本章节全量清单）→「⭐ 重点 / 🧩 难点 / 🎯 考点」
- 每条知识点附带 **📖 详细讲解 + ✏️ 例题 + ⚠️ 易错提醒**
- **📖 电子课本**：按人教版/统编版新教材真实单元目录（册→单元→节）浏览，每节配知识点精要与学习跳转
- 基于人教版新教材（2019 版）/ 统编版，结合近五年高考命题规律整理

## 智能学习
- 🧠 **三级掌握程度**：点击知识点左侧圆点循环切换「未掌握 → 学习中 → 已掌握」，学段/模块进度条按权重实时统计（已掌握 1.0 / 学习中 0.5），本机自动保存
- 💡 **点击任意知识点展开讲解面板**：讲解原理、例题解析、易错提醒一应俱全
- 🔍 全站搜索支持检索知识点正文 + 讲解内容，结果高亮、一键跳转
- 🎲 随机复习抽查：弹窗内直接展示讲解与易错提醒，可当场标记掌握状态

## 书香界面与动态背景
- 🖋️ 宣纸底色 + 墨色文字 + 楷书/宋体排版 + 朱砂印章点缀，典雅书香风（暗色主题为墨色夜）
- 🎨 **每科专属动态背景**：语文水墨墨点与竹叶、数学几何图形与公式、英语书页字母、物理原子轨道、化学分子结构与化学式、生物细胞与DNA
- 卡片悬停朱砂底线、水墨晕染背景随科目变色、滚动浮现、打字机文案
- 🌙/☀️ 明暗主题切换（默认为书香浅色）

## 知识关系图谱（Obsidian 风格）
- 🗺️ 顶栏/侧边栏/首页均可进入「知识关系图谱」：165 个知识模块节点 + 179 条关系边
- 力导向布局：节点自动排布，可**拖动节点重排、滚轮缩放、拖动空白平移**
- 悬停节点**高亮其关联网络**（弱化无关节点），跨学科关联用虚线标注（如数学导数→物理电磁感应、化学平衡→生物生态系统）
- 点击节点一键跳转到对应学习模块；支持按学科过滤
- 节点大小 = 知识点数量，颜色 = 学科

## 电子课本（按单元目录编排）
- 📖 顶栏/侧边栏/首页均可进入「电子课本」：按真实教材目录浏览（学科 → 册 → 单元 → 节）
- 左侧目录树（可折叠单元）+ 右侧内容面板（节的知识点精要：课本知识点/重点/难点/考点）
- 每一节映射到对应知识模块，一键「进入深度学习」；高三为「高考总复习」专题目录
- 覆盖全部教材册：数学/物理/化学/生物 必修一、二 + 选择性必修一/二/三；语文 必修上/下 + 选择性必修上/中/下；英语 必修一/二/三 + 选择性必修一/二/三/四
- 内置**官方正版电子教材链接**（教育部「国家中小学智慧教育平台」basic.smartedu.cn、人民教育出版社 pep.com.cn 等），可跳转在线阅读正版教材

## 目录结构
```
index.html            ← 最终成品（单文件，双击打开）
src/template.html     ← 页面模板（含占位符 __DATA_JSON__）
data/*.json           ← 六科知识数据（chinese/math/english/physics/chemistry/biology）
data/enrich-*.json    ← 六科讲解层数据（讲解/例题/易错提醒）
data/textbook-*.json  ← 六科课本知识点数据（课本章节全量清单）
data/toc-*.json       ← 六科教材目录数据（册→单元→节，映射知识模块）
build.mjs             ← 构建脚本：合并数据 → 生成 index.html
validate.mjs          ← 数据 + 讲解层覆盖率校验
final-check.mjs       ← 最终产物验证
graph-test.mjs        ← 知识图谱布局模拟测试
gh-api.mjs            ← GitHub 部署辅助（创建仓库/启用 Pages）
upload-file.mjs       ← GitHub Contents API 兜底上传
verify-live.mjs       ← 线上页面验证
server.mjs            ← 本地静态服务器（node server.mjs → http://127.0.0.1:8088）
```

## 使用
```bash
node validate.mjs      # 校验六科数据 + 讲解层覆盖率
node graph-test.mjs    # 测试知识图谱布局
node build.mjs         # 重新构建 index.html
node final-check.mjs   # 验证最终产物
node server.mjs        # 本地预览（http://127.0.0.1:8088）
```
